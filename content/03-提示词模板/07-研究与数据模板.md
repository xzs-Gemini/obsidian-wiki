# 研究与数据模板

```text
请研究并整理【对象集合】，输出到【数据文件/报告】。

事实标准：
- 优先官方/权威直接来源；
- 必要时补充公开反馈，但与正式来源分层；
- 保存真实 URL、访问时间、提取事实和判断理由；
- 搜索结果页、摘要或同名对象不能直接当证据；
- 无法确认就保持 null/未知/无可用真实数据。

数据规则：
- 以【唯一ID】关联；
- 明确状态枚举；
- 检查重复、缺失、孤立引用、字段错配和派生数据一致性；
- 生成过程应幂等，可从源数据重建。

批次规则：【数量与检查点】。
最终运行：【类型检查、数据库检查、集成检查、运行时抽查】。
```

## 素材映射追加句

```text
先检查文件元数据、方向、主体语义、版权/授权和目标 ID。可疑素材先隔离，不要因为文件名或相似地名强行匹配。
```
