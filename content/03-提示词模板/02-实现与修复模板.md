# 实现与修复模板

```text
请在【项目路径】实现/修复【目标】。

现状：【当前行为、已知问题、相关文件】
必须保留：【现有功能、视觉、数据、接口】
允许修改：【明确目录/文件/对象】
禁止修改：【无关模块、数据库、依赖、素材、配置】

执行要求：
1. 先复现并确认根因；
2. 选择最小可维护改动；
3. 不覆盖用户未提交内容；
4. 修改后运行【静态检查/测试/构建】；
5. 真实走一遍【正常路径】与【异常路径】；
6. 清理临时数据和调试状态。

完成定义：
- 【功能结果】；
- 【无回归要求】；
- 【错误/警告门槛】；
- 【视觉/性能门槛】。

若无法真实验证，明确标记未验证。最终列出修改文件、验证证据、残留风险和下一步。
```

## 最小修复追加句

```text
不要顺手重构。若发现邻近问题，只记录，不在本次处理。
```

## 防伪完成追加句

```text
不要通过降低验收阈值、写死结果、伪造状态、跳过流程或使用测试专用捷径来制造通过。
```
