# Computer Use 模板

```text
请使用 Computer Use 操作【应用名】中的【明确窗口/流程】。

目标：【最终界面状态或要验证的行为】
允许操作：【点击/输入/拖拽/设置项】
不要操作：【其他应用、账号、安全设置、终端、无关文件】

先列出应用并只选择一个明确窗口；每次动作后重新观察界面，不复用旧坐标或旧元素索引。
遇到弹窗、窗口切换或失败时重新定位窗口。
涉及删除、发送、安装、授权、上传或提交前，按确认规则停下。

完成后用截图和界面文本验证结果，并说明任何无法由 GUI 证明的部分。
```

## GUI 复现 Bug

```text
打开【应用】，从【入口】按【步骤】复现问题。先记录复现证据，再修复最小代码路径，然后用完全相同的 GUI 步骤重测。不要用直接改状态或跳转页面代替用户路径。
```
