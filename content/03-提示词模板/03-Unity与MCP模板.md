# Unity 与 MCP 模板

```text
请使用 Unity MCP 在【Unity 项目路径】完成【目标】。

先确认：Unity 实例、活动项目、Unity 版本、当前场景、Play/Edit Mode、Console 基线、Build Settings 和相关对象层级。

必须保留：【已有场景/预制体/美术/输入/数据库/默认启动行为】
允许修改：【场景、脚本、对象、参数】
禁止修改：【不相关场景、Packages、ProjectSettings、素材】

实施后必须：
1. 等待编译完成；
2. 运行脚本/场景验证；
3. 在 Play Mode 从真实入口触发；
4. 验证正常路径和至少一个边界条件；
5. 检查 Console 是否有本次新增错误或警告；
6. 保存场景；
7. 清除测试 PlayerPrefs/调试标志/临时对象；
8. 恢复默认启动场景并退出 Play Mode（除非我要求保持运行）。

视觉相关时保存 QA 截图，但不要把“有截图”当作功能正确的唯一证据。
```

## 物理/动画错位追加句

```text
请分别测量碰撞体、逻辑锚点和实际渲染像素/网格，不要只看 Transform 中心。逐帧或逐状态验证最差情况。
```

## 输入系统追加句

```text
同时验证键盘、手柄及设备切换；避免把测试输入写进正式逻辑。验证第三次输入拒绝、空中/地面限制和同时按键。
```
