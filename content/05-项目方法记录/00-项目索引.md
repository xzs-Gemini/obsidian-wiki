# 项目方法记录

> 以下是基于过往任务抽象出的项目工作法。只记录思路、过程、验证和坑，不展示真实成品、完整业务数据、个人材料或未公开成果。

| 项目类型 | 核心方法 | 代表性坑 |
|---|---|---|
| [[05-项目方法记录/01-移动应用与数据工程|移动应用与数据工程]] | 单一事实源、ID 关联、证据分层、批次验证 | 假占位符、状态错配、同名素材、隧道失效 |
| [[05-项目方法记录/02-Unity文旅游戏|Unity 文旅游戏]] | 复用场景、小步迭代、Play Mode 闭环 | 逻辑正确但视觉错位、临时状态污染 |
| [[05-项目方法记录/03-XR与Unity环境|XR 与 Unity 环境]] | 版本矩阵、官方 Demo、硬件/Runtime 分层 | 安装不等于运行，模拟通过不等于真机通过 |
| [[05-项目方法记录/04-本地模型与Tool Calling|本地模型与 Tool Calling]] | 分层验收：模型→API→工具→业务 | 单次工具调用通过但完整工具集不稳定 |
| [[05-项目方法记录/05-文档简历与演示|文档、简历与演示]] | 事实矩阵、模板保真、渲染验收 | 无证据内容被润色成事实、版面溢出 |
| [[05-项目方法记录/06-Obsidian与Codex集成|Obsidian 与 Codex 集成]] | 链路分段、CLI/插件/GUI 分层验证 | 后端可用但 GUI 抓取失败、前置条件不足 |

## 跨项目共同模式

```text
确定真实基线
→ 保护已有资产
→ 建立单一事实源
→ 做最小改动
→ 静态 + 构建 + 运行 + 视觉验证
→ 清理测试状态
→ 写交接与下一步
```
