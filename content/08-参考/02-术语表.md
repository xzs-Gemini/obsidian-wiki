# 术语表

| 术语 | 含义 |
|---|---|
| Agent | 能理解任务、调用工具并持续工作的模型执行者 |
| Main agent | 负责需求、决策、写入整合与最终交付的主代理 |
| Subagent | 由主代理委派边界清晰子任务的代理 |
| Skill | 面向特定任务的可复用流程、资源和可选脚本 |
| Plugin | 可安装的 Skill、MCP、Connector 等能力组合 |
| MCP | 让 Codex 通过结构化协议访问外部工具与上下文 |
| Connector/App | 已授权的外部服务连接，例如云文件或协作系统 |
| Computer Use | 操作桌面 GUI 的能力 |
| Browser Use | 面向网页与本地 Web 应用的浏览器控制能力 |
| `AGENTS.md` | 项目/目录级持久工作规则 |
| Memory | 跨任务保存的稳定偏好和上下文 |
| Automation | 定时或周期性执行的任务 |
| Baseline | 修改前可复核的版本、数据、测试和状态 |
| Handoff | 中断或交付时的可恢复状态说明 |
| Fail closed | 证据不足时保持未知/拒绝，而不是猜测通过 |
| Idempotent | 同样输入重复执行，结果保持一致且不重复污染 |
| Runtime acceptance | 在真实运行环境中验证功能与状态 |
| E2E | 从用户入口到最终结果的端到端流程 |
| Fallback | 主要方案失败时的安全替代；不等同于主要方案通过 |
| Truth source | 权威主数据源，其他文件由它派生 |
