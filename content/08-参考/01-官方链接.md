# 官方链接

以下链接用于校准本知识库中的 Codex 产品用法；产品界面和可用性会变化，以当前官方文档与本机可调用能力为准。

- [Computer Use](https://learn.chatgpt.com/docs/computer-use)：桌面端安装、权限、适用场景与 Windows 前台限制。
- [Skills & Plugins](https://learn.chatgpt.com/docs/skills-and-plugins)：Skill 与 Plugin 的用途和调用方式。
- [Build skills](https://learn.chatgpt.com/docs/build-skills)：Skill 目录、显式/隐式触发与创建方法。
- [AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md)：全局和项目级指令发现与优先级。
- [Subagents](https://learn.chatgpt.com/docs/agent-configuration/subagents)：并行代理的适用场景、成本与上下文管理。
- [OpenAI 模型指引](https://developers.openai.com/api/docs/guides/latest-model)：当前模型能力与提示词建议。

## 本地环境规则来源

Computer Use 的具体操作循环与安全限制还来自本机已安装 Computer Use Skill。它比公开页面更具体地规定了窗口选择、状态刷新、焦点、坐标失效、恢复与动作确认方式。该内容可能随插件版本更新，使用时应让 Codex 重新读取当前 `SKILL.md`。
