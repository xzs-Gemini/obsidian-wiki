# 工具选择总览

## 四层能力模型

| 层 | 解决什么 | 例子 |
|---|---|---|
| 指令层 | 告诉 Codex 按什么流程做 | Prompt、`AGENTS.md`、Memory、Skill |
| 操作层 | 对本地或远程对象执行动作 | Shell、Apply Patch、Computer Use、Browser |
| 集成层 | 结构化读取或控制专业系统 | Unity MCP、Figma MCP、Connector、插件 |
| 编排层 | 让任务持续或并行 | Subagents、Automations、Goals/长任务 |

## 选择原则

1. 有专用 MCP/Connector 时优先它。
2. 本地文件能直接处理时，不要用 GUI 点编辑器。
3. 网页测试优先内置 Browser；桌面软件或 GUI-only 问题再用 Computer Use。
4. 重复流程用 Skill；项目持久规则用 `AGENTS.md`。
5. 独立、读重型工作可交给 Subagents；强耦合写入保留单主代理。
6. 定时/重复执行用 Automation，不要让普通对话假装“后台等待”。

## 常用组合

### Unity 开发

`AGENTS.md → Unity MCP → 文件修改 → Play Mode → Console/场景验证 → QA 截图`

### GUI 验收

`代码/文件工具 → 启动应用 → Computer Use 走用户流程 → 截图/界面状态 → 修复 → 同路径复测`

### 文档交付

`Documents/Presentations Skill → 生成/修改 → 渲染 → 视觉检查 → 结构检查 → 交付`

### 大规模研究

`Web Search/Connector → 固定队列 → 数据生成器 → 批次验证 → 报告 → Handoff`
