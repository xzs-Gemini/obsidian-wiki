# Windows 环境问题

## 文件锁与 EPERM

### 症状

- `npm ci` 无法清理目录；
- 缓存路径指向异常磁盘位置；
- 依赖目录处于半安装状态。

### 方法

1. 检查实际 npm cache 配置与锁文件；
2. 确认占用进程；
3. 修复缓存位置；
4. 清理明确的半成品目录；
5. 从 `npm ci` 和依赖完整性重新开始完整预检；
6. 保留 lockfile，除非任务明确要求升级依赖。

## GUI 前台争用

Computer Use 在 Windows 当前桌面运行，用户同时操作会导致焦点漂移或输入被拒绝。安排空闲时段，保持目标应用可见、设备解锁，并在任何中断后重新观察窗口。

## UAC、许可与系统弹窗

安装过程中的 UAC、软件条款或硬件权限不是普通应用步骤。需要用户介入时，准确描述当前弹窗和下一动作，不重复点击或绕过。

## 中文路径与编码

- PowerShell 读取中文 Markdown 使用明确 UTF-8；
- 文件创建后回读并比对；
- 第三方工具对中文路径支持不一致时，用可回滚的短路径/链接方案；
- 不因为终端乱码判断文件内容已经损坏。

## 服务/端口/隧道

```text
进程 → 本地端口 → 本地请求 → 公网隧道 → manifest → bundle → 客户端
```

按层定位，不要一次性重启所有东西。旧隧道和新服务也可能串错，必须核对目标 Host 与响应内容。

## Git 假仓库

在声称“已提交”前，检查仓库是否真的有 HEAD、objects、config 和分支状态。空 `.git` 目录或被复制残缺的元数据不具备可恢复性。
