# 开始前检查表

- [ ] 目标与最终交付清楚
- [ ] 项目/文件/应用的准确路径清楚
- [ ] 已读取适用的 `AGENTS.md`
- [ ] 已读取 README、交接文档和最近报告
- [ ] 已确认 Git/文件现状，不覆盖用户改动
- [ ] 已记录版本、数量、错误和运行状态基线
- [ ] 已区分回答、诊断、修改、创建、监控或外部操作
- [ ] 已选定首选工具/MCP/Skill
- [ ] 已明确允许修改与禁止修改范围
- [ ] 已明确必须验收与可选优化
- [ ] 已识别安装、删除、发送、上传、授权、发布等确认点
- [ ] 长任务已有固定队列、检查点和停止条件
