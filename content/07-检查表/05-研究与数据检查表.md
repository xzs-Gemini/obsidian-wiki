# 研究与数据检查表

- [ ] 对象集合与唯一 ID 固定
- [ ] 数据 schema 与状态枚举明确
- [ ] 官方/权威来源优先
- [ ] 公开反馈与正式来源分层
- [ ] 保存真实 URL、访问时间与提取事实
- [ ] 搜索摘要没有直接当证据
- [ ] 同名对象已排除
- [ ] 无证据内容保持未知/无可用数据
- [ ] 没有为了覆盖率编造信息
- [ ] 批次检查点已执行
- [ ] 重复 ID 为 0
- [ ] 缺失 ID 为 0（或有明确清单）
- [ ] 孤立引用为 0
- [ ] 派生数据可从主数据重建
- [ ] 生成脚本幂等
- [ ] 数据库、适配器与运行时读取一致
- [ ] 报告累计数与真实数据库一致
- [ ] 版权/授权状态与事实状态分开
