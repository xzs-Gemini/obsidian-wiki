# Unity 任务检查表

## 开始

- [ ] 正确 Unity 实例和项目
- [ ] Unity/包版本已确认
- [ ] 当前场景与 Build Settings 已确认
- [ ] 当前处于 Edit Mode
- [ ] Console 基线已记录
- [ ] 相关对象层级、预制体和脚本已读取

## 修改

- [ ] 复用现有组件/资源
- [ ] 不修改不相关场景和 ProjectSettings
- [ ] 输入、层级、Sorting Layer、Collider、Canvas 模式匹配
- [ ] 资源导入设置、透明度、尺寸与压缩正确
- [ ] 场景与资产已保存

## 验收

- [ ] 编译完成
- [ ] 脚本验证通过
- [ ] 场景无缺失脚本/破损预制体
- [ ] 从真实入口进入流程
- [ ] 正常、重复和失败路径至少各一次
- [ ] 键盘/手柄/切换验证（若适用）
- [ ] 物理锚点与视觉像素对齐
- [ ] UI 安全区、遮挡、动效和文案可读
- [ ] Console 无本次新增 Error/Warning
- [ ] QA 截图已保存（若需要）

## 清理

- [ ] 测试 PlayerPrefs 清除
- [ ] 调试/验收开关恢复
- [ ] 临时对象与截图清理
- [ ] 默认 Play Mode 启动场景恢复
- [ ] 退出 Play Mode
