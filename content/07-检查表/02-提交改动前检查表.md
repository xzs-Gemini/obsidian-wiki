# 提交改动前检查表

- [ ] 根因已经被证据支持
- [ ] 改动是本次范围内的最小方案
- [ ] 没有覆盖用户未提交修改
- [ ] 没有顺手重构无关模块
- [ ] 没有引入未经允许的新依赖
- [ ] 数据迁移/生成脚本可重复运行
- [ ] 错误处理与第二次运行生命周期已考虑
- [ ] 测试没有降低标准或写死结果
- [ ] 静态检查通过
- [ ] 构建/编译通过
- [ ] 正常路径已运行
- [ ] 关键异常/重复路径已运行
- [ ] 日志/Console 无本次新增错误
- [ ] 视觉或渲染已检查（若适用）
- [ ] 临时文件、调试标志、测试状态已清理
- [ ] 变更文件与未处理发现已记录
