# 交付前检查表

- [ ] 用户目标已经实际完成
- [ ] 交付文件存在且可打开
- [ ] 输出路径正确
- [ ] 没有覆盖原文件（除非明确要求）
- [ ] 所有必须验收已通过
- [ ] 已验证与未验证清楚分开
- [ ] 没有把模拟、fallback、搜索摘要或单次成功写成全面通过
- [ ] 变更范围与禁止项核对完成
- [ ] 测试环境恢复或当前运行状态已说明
- [ ] 临时文件与敏感信息已清理
- [ ] 最终回复先给结果，再给证据和路径
- [ ] 残留风险与下一步简短明确
- [ ] 长任务交接包含下一 ID/断点
- [ ] 项目记忆/日志已更新
